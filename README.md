# Avazbek Yoqubov — portfolio

Shaxsiy portfolio sayti: loyihalar, tajriba va ko'nikmalar. O'zbek va ingliz tillarida, qorong'i/och mavzu.

**Sayt:** https://avazbektoxirjonovich-commits.github.io/

Oddiy statik sayt — build kerak emas:

```
index.html   sahifa tuzilishi
styles.css   dizayn (bento grid, mavzular)
main.js      loyihalar, tarjimalar, modal oyna
assets/      rasm, skrinshotlar, rezyume PDF
```

Lokal ko'rish: `python -m http.server` → http://localhost:8000

Yangi loyiha qo'shish — `main.js` dagi `PROJECTS` ro'yxatiga bitta obyekt qo'shiladi (`uz` va `en` matnlari bilan).
